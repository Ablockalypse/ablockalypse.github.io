About

Solo Arena Sweep.

Laser Tag Demo is a solo arena challenge built around precise tagging in a ray-traced space. One focused session: read the brief, clear two waves, walk out.

The arena uses a mirrored A/B layout with spawn points. This demo is single-player only — no local co-op and no online multiplayer.

What you get

  • One focused solo mode you can finish in a short session
  • A ray-traced look that shows the Digiflux / Vulkan lighting path
  • A Linux build — RTX-capable hardware recommended

What this is not

  • Not multiplayer — no local co-op, no online play
  • Not a Windows build (yet)
  • Not the full Laser Tag product

Requirements

Linux only. The ray-traced presentation is meant for RTX-capable GPUs. Expect reduced quality or performance on hardware without that support.
